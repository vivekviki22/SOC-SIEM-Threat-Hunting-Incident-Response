# Threat Hunting Evidence

This section contains evidence of threat hunting and alert investigation performed using the Wazuh Threat Hunting interface.

## Activities

- Filtering events by Wazuh rule ID
- Reviewing normalized security events
- Investigating authentication failures
- Reviewing privilege-related alerts
- Correlating Windows and Linux security activity
- Analyzing event timelines
- Identifying affected endpoints and user accounts

The threat-hunting workflow was used to narrow large volumes of security telemetry into relevant events for investigation and incident analysis.
