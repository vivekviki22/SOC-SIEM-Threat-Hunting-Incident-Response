# SOC Incident Response Playbook

This directory contains the Incident Response Playbook developed for the SOC & SIEM Threat Hunting and Incident Response project.

The playbook provides structured procedures for:

- Alert triage and identification
- Security-event investigation
- Event correlation
- Brute-force authentication incidents
- Privileged-access incidents
- Account manipulation
- Potential data-exfiltration activity
- Containment
- Eradication
- Recovery
- Evidence collection
- Lessons learned

The playbook demonstrates how security alerts detected through Wazuh can be converted into a structured SOC incident-response workflow.
